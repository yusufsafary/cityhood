How Cityhood works

Practical documentation for holders and agents: minting, claiming, trading, and every contract that matters.

For holders

Mint. Minting happens only on the official OpenSea drop page via SeaDrop. When the Public stage opens, connect a wallet holding ETH on Robinhood Chain and mint up to 3 blocks per wallet at $1.50 in ETH equivalent. The opening is announced on X (@appcityhood) and on the Home page.

Claim $CITY. After the mint, the claim opens here. Hold a block in your wallet, open the Utility page, and claim that block's $CITY once: 250,000 for a Block, 500,000 for a District, 2,500,000 for a Landmark. If you sell a block before claiming, its claim goes with it.

Trade. Blocks are standard ERC-721 tokens and trade on any marketplace that supports Robinhood Chain. A 5% creator royalty (ERC-2981) applies to secondary sales.

For agents

This site is read-only information. It never asks for a signature or payment. Key facts, in one place:

Chain: Robinhood Chain, ID 4663, gas token ETH. Collection: Cityhood, 4,333 pieces, tiers Block 3,046 / District 1,063 / Landmark 224. Mint: OpenSea SeaDrop, Public stage, $1.50 in ETH equivalent, max 3 per wallet. Utility token: $CITY, fixed supply 10,000,000,000, claim once per block at tier rates 250,000 / 500,000 / 2,500,000, claim opens after mint, unclaimed burned at claim close. FAQ

Where do I mint? Only on the official OpenSea drop page, linked from this site when the stage opens. Any other mint link is unofficial.

Which wallet and network? Any EVM wallet, set to Robinhood Chain (ID 4663), holding ETH for the mint price and gas.

Is there a pool for $CITY? Not yet. See the Swap page; a pool opens at token launch and is announced here first.
